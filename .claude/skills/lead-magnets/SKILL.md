# Lead Magnets Agent

Шаблонный скилл. Устанавливается в любой проект и настраивается под конкретного клиента через бриф — не привязан к одной компании или продукту. Один и тот же скилл работает для разных клиентов агентства: у каждого клиента — своя папка с данными (см. «Где что хранится» ниже).

Главная идея: лид-магнит — это не файл, который никто не читает, а **страница сайта в формате лонгрида** с интерактивными элементами, которая прогревает читателя и ведёт его к целевому действию (заявка, кнопка, переход к продукту).

## Когда использовать

- Просят создать/обновить лид-магнит, прогревающую страницу, интерактивный лонгрид
- Просят проанализировать текущие лид-магниты клиента или лид-магниты конкурентов
- Просят собрать/обновить бриф по продукту и ЦА для будущих лид-магнитов
- Просят посмотреть аналитику по уже опубликованному лид-магниту и предложить улучшения

## Как работает агент — 7 фаз

Полный алгоритм с правилами по каждой фазе — в `references/workflow.md`. Читай его первым в любой сессии работы с этим скиллом — это главный файл.

| # | Фаза | Что делает | Чекпоинт согласования? |
|---|------|-----------|------------------------|
| 0 | Бриф | Собирает/обновляет факты о компании, продукте, ЦА, воронке | Нет — используется сразу |
| 1 | Аудит | Разбирает текущие лид-магниты клиента и воронку целиком | Нет |
| 2 | Конкуренты | Ищет по открытым источникам, что и как делают конкуренты | Нет (но спрашивает клиента, если не уверен в списке конкурентов) |
| 3 | Структура | Собирает сценарий/план разделов нового лид-магнита | **Да, обязательно** — без «ок» дальше не идёт |
| 4 | Сборка | Пишет текст, собирает дизайн и интерактив в готовую HTML-страницу | Нет (после утверждения структуры) |
| 5 | Деплой | Публикует страницу (или отдаёт файл, если доступа нет) | Прод — да, превью — нет |
| 6 | Аналитика | Смотрит Яндекс.Метрику, предлагает конкретные правки | Да — правки не льются в прод молча |

## Где что хранится

Бриф и все материалы — не внутри скилла, а в рабочем проекте клиента, в папке `lead-magnets/`:

```
lead-magnets/
  brief.md                     ← бриф клиента (создаётся из templates/brief-template.md)
  competitors.md                ← находки по конкурентам, дополняется со временем
  pages/
    <slug-темы>/
      structure.md               ← согласованный сценарий (Фаза 3)
      index.html                  ← готовая страница (Фаза 4)
      analytics-log.md             ← история разборов аналитики и правок (Фаза 6)
```

Если папки `lead-magnets/` в проекте ещё нет — создай её при первом запуске. Если `brief.md` уже существует — это Фаза 0 «обновление», не пересобирай бриф с нуля, дополни его.

## Маршрутизация по подкоманде

| Подкоманда | Что делать | Файл |
|---|---|---|
| `brief` | Собрать или обновить бриф (Фаза 0) | `references/brief.md` |
| `audit` | Разобрать текущие лид-магниты и воронку (Фаза 1) | `references/workflow.md` §1 |
| `research` | Конкурентный ресёрч (Фаза 2) | `references/competitors.md` |
| `structure` | Собрать сценарий и вынести на согласование (Фаза 3) | `references/structure.md` |
| `build` | Собрать полную страницу (Фаза 4) | `references/build-page.md` + `references/interactive-blocks.md` |
| `deploy` | Опубликовать (Фаза 5) | `references/deploy.md` |
| `analyze` | Разобрать аналитику и предложить правки (Фаза 6) | `references/analytics.md` |

Без явной подкоманды — определи фазу по контексту: нет `lead-magnets/brief.md` → начни с Фазы 0; бриф есть, но нет конкретной задачи → спроси, что делаем (новый лид-магнит / обновить бриф / разобрать аналитику существующего).

## Шаблоны

| Шаблон | Назначение |
|---|---|
| `templates/brief-template.md` | Стартовая структура файла брифа |
| `templates/structure-template.md` | Стартовая структура файла сценария (Фаза 3) |
| `templates/page-template.html` | Базовый каркас страницы-лонгрида: мобильный первый, брендируемые CSS-переменные, слоты под интерактивные блоки, форма заявки, счётчик Яндекс.Метрики |

## Скрипты

| Скрипт | Назначение |
|---|---|
| `scripts/validate-page.cjs` | Проверяет готовую страницу перед публикацией: мета-теги, alt у картинок, счётчик метрики, форма/CTA, незаполненные плейсхолдеры |

Запуск: `node .claude/skills/lead-magnets/scripts/validate-page.cjs lead-magnets/pages/<slug>/index.html` — гоняй перед каждым деплоем (Фаза 5), не публикуй, пока скрипт не вернёт `OK`.

## Стиль общения (обязательно для всех фаз)

- Простой язык, без маркетингового жаргона — скилл ставит не обязательно маркетолог.
- Двигайся блоками вопросов по ситуации, а не вываливай все вопросы сразу.
- Явно называй, на каком ты сейчас шаге из 7 фаз.
- Не публикуй в прод и не переписывай уже опубликованную страницу без явного подтверждения — это необратимое публичное действие.
