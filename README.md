# CMO Community (cmo-razbory)

Telegram-бот + веб-приложение для закрытого комьюнити «Разборы CMO» — платформы для маркетинг-директоров с курсом, квизами-разборами на ИИ, random coffee и админкой.

Работает как единый **Cloudflare Worker** (`worker.js`) с хранением данных в **Cloudflare KV**.

## Возможности

- **Telegram-бот** — вебхук-обработчик, регистрация и онбординг пользователей.
- **Mini App / веб-кабинет** — программа курса, задания, прогресс, вопросы.
- **ИИ-квизы**:
  - Quiz 1 — AI Maturity Score (шаблонный, без ИИ).
  - Quiz 2 — разбор лендинга через Claude.
  - Quiz 3 — многоходовой диалог с «нутрициологом» (голос + текст).
- **Лид-магниты** — интерактивные лендинги-разборы (например, «Куда утекают пациенты стоматологии»), исходники в `lead-magnets/`.
- **Random Coffee** — авто-формирование пар раз в неделю (пн 12:00 МСК) и напоминание/оценка (пт), через cron-триггер.
- **Админка** (`/admin`) — пользователи, аналитика, CRM, посещаемость воркшопов, активность в чате, платежи.
- **Платежи** — приём вебхуков от edsofa.ai.
- **Превью-ссылка `/board`** — пустая страница с OG-тегами (заголовок, описание, картинка «Подборка вакансий») для красивого превью в Telegram; сразу редиректит на https://cmo.pro/board. Картинка — `board/og-vacancies.jpg`, после замены: `node board/build-worker-assets.mjs` и поднять `BOARD_OG_VERSION` в `worker.js`.
- **События** — список ивентов с генерацией `.ics`-файлов для календаря.
- **План воронки** (`plan/`, на воркере — `/plan`) — рабочее пространство для плана: документы как в Notion (блоки, меню «/», задачи, таблицы, перетаскивание, вложенность) и доски как в Miro (стикеры, фигуры, стрелки, фреймы, масштаб). Предзаполнено итогами обсуждения воронки «3 дня эфиров» (`plan/seed.md`). Без входа всё хранится в браузере; кнопка «Подключить общий план» (пароль админки) включает общий план команды через `/api/plan` и KV. После правки исходников: `node plan/build-worker-assets.mjs`. Локально можно открыть `plan/index.html` прямо из папки.
- **CRM лички** (`crm/`, на воркере — `/crm`) — переписка с лидами из личного Telegram Олега. Личка подключена к инбоксу воркера tasktracker (репозиторий mybrand-smm); `/crm` ходит в его API через service binding `INBOX` и секрет `INBOX_API_TOKEN` (= `INBOX_CMO_TOKEN` на tasktracker). Что внутри: вход по логину и паролю (роли админ и менеджер, раздел «Команда»); разбор новых диалогов карточками «в CRM / не добавлять» (свайп или стрелки, только админ); два вида: чаты (список и диалог, как в amoCRM) и таблица с рассылкой по выбранным; этапы, ответственный, заметка, задачи с датой и примечанием; уведомления о новых сообщениях и сроках задач; подпись автора под каждым исходящим сообщением; журнал действий и времени в системе с ИИ-разбором работы сотрудника; база знаний как в Notion со скриптами и файлами. Стартовые скрипты — `crm/kb/*.md`, при первом открытии копируются в KV, дальше правятся в интерфейсе. После правки исходников: `node crm/build-worker-assets.mjs`.
- **ИИ-ассистент задач** (`ai-assistant/`, на воркере — `/ai-assistant`) — интерактивная страница для воркшопа: схема системы с переключением источников (рабочие чаты, Business-бот в личке, почта, календарь, CRM, голосовые, дашборд), разбор сообщения в задачу, сцены в Telegram, доска задач с «машиной времени» и лентой напоминаний, лестница напоминаний с тоном, база знаний, вопросы к ИИ по живой доске, триггеры из дашборда и CRM, идеи и конструктор с промптом для Claude Code. Всё работает в браузере на демо-данных. После правки: `node ai-assistant/build-worker-assets.mjs`.
- **Дашборд отдела маркетинга** (`dashboard/`, на воркере — `/dashboard`) — сквозная аналитика по Яндекс.Директу, VK Ads, Telegram Ads, Метрике с поведением на страницах, коллтрекингу, amoCRM, Telegram-боту и Google Sheets: ИИ-выводы, вопросы к ИИ по цифрам, обновление по расписанию и по кнопке, дайджест руководителю. Собрать и открыть: `node dashboard/collectors/collect.js`, затем `dashboard/index.html`.

## Стек

- Cloudflare Workers (`wrangler.toml`)
- Cloudflare KV (хранилище)
- Telegram Bot API
- Claude API (анализ в квизах)

## Структура репозитория

```
worker.js           — весь backend/frontend воркера (роутинг, API, HTML/CSS/JS)
wrangler.toml        — конфигурация Cloudflare Worker, KV, cron
lead-magnets/         — исходники и структура лид-магнитов
ai-assistant/         — страница /ai-assistant: интерактивный разбор ИИ-ассистента задач для воркшопа
dashboard/            — дашборд отдела маркетинга: коллекторы API, модель данных, ИИ-аналитика
plan/                 — страница /plan: документы и доски для плана воронки (index.html, plan.js, plan.css, seed.md)
crm/                  — страница /crm: CRM лички (api.js — backend, index.html/crm.js/crm.css — интерфейс, kb/ — стартовые скрипты)
.claude/skills/       — скиллы для Claude Code (дизайн, брендинг, лендинги и т.д.)
```

## Настройка и деплой

1. Установить [Wrangler](https://developers.cloudflare.com/workers/wrangler/).
2. Задать секреты:
   ```
   wrangler secret put BOT_TOKEN               # токен Telegram-бота
   wrangler secret put ADMIN_ID                 # chat id для админ-уведомлений
   wrangler secret put PAYMENTS_WEBHOOK_SECRET   # секрет вебхука edsofa.ai
   ```
3. Деплой:
   ```
   wrangler deploy
   ```
4. Установить вебхук Telegram: открыть `/setup-webhook` на домене воркера.

## Локальная разработка

```
wrangler dev
```
