# Дашборд отдела маркетинга

Статичный дашборд в светлой теме, который собирает данные из Яндекс.Директа, Яндекс.Метрики,
Telegram-бота, amoCRM и Google Sheets, приводит их к единому виду, считает ИИ-инсайты и шлёт
дайджест руководителю в Telegram.

Демо-версия открывается двойным кликом по `index.html` — без сервера, без ключей, без интернета.

```
dashboard/
  index.html            вёрстка дашборда
  app.js                отрисовка (Chart.js + немного SVG), читает только готовый JSON
  vendor/               Chart.js локально, чтобы страница работала офлайн
  data/
    dashboard.json      результат сборки — единая модель данных
    dashboard.js        тот же JSON как window.DASHBOARD_DATA (для открытия по file://)
  collectors/
    collect.js          оркестратор: собрать → нормализовать → посчитать инсайты → записать
    demo_source.js      генератор демо-данных в формате реальных API
    normalize.js        приведение пяти источников к одной модели
    insights.js         инсайты: правила + Claude API, плюс текст дайджеста
    yandex_direct.js    Reports API v5
    yandex_metrika.js   Reporting API
    telegram_bot.js     события бота + Bot API
    amocrm.js           API v4
    google_sheets.js    Sheets API v4 (план и офлайн-расходы)
    config.example.json шаблон конфига
  automation/           автообновление: GitHub Actions и cron на Cloudflare Worker
```

## Быстрый старт (демо)

```bash
cd dashboard/collectors
node collect.js                  # соберёт демо-данные за последние 28 дней
open ../index.html               # или просто открыть файл в браузере
```

Никаких зависимостей ставить не нужно: только Node 18+ (нужен встроенный `fetch`).

## Боевой режим

1. `cp config.example.json config.json` и заполнить доступы.
   Значения вида `"env:DIRECT_TOKEN"` подставляются из переменных окружения — токены в репозиторий не попадают.
2. Проверить по одному источнику за раз: выключайте в `config.json` всё, кроме проверяемого, — так видно,
   где именно не хватает прав.
3. Запустить:

```bash
DIRECT_TOKEN=... METRIKA_TOKEN=... AMO_TOKEN=... SHEETS_API_KEY=... \
ANTHROPIC_API_KEY=... node collect.js --mode=live --ai
```

Флаги: `--mode=live|demo`, `--ai` (инсайты через Claude API), `--notify` (дайджест в Telegram),
`--from=YYYY-MM-DD --to=YYYY-MM-DD`, `--days=28`.

Если источник отвалился, сборка не падает целиком: он помечается статусом `error`,
остальные блоки считаются, а в шапке дашборда и в разделе «Откуда берутся данные» видно, что сломалось.

## Что нужно получить до начала (доступы)

| Источник | Что нужно | Где взять |
|---|---|---|
| Яндекс.Директ | OAuth-токен с доступом к Директу, для агентства — ещё `Client-Login` | oauth.yandex.ru → приложение с правами Директа |
| Яндекс.Метрика | OAuth-токен, номер счётчика, id цели «Заявка» | тот же OAuth + Метрика → Настройка → Цели |
| Telegram-бот | токен бота и эндпоинт с событиями воронки | @BotFather + собственное хранилище событий бота |
| amoCRM | долгоживущий токен интеграции, id полей «канал», «кампания», «квалификация» | amoCRM → Интеграции → Создать интеграцию |
| Google Sheets | id таблицы + API-ключ (таблица «по ссылке») или сервисный аккаунт | console.cloud.google.com → Sheets API |
| Claude API | `ANTHROPIC_API_KEY` | console.anthropic.com |

## Инсайты

Считаются в два слоя:

1. **Правила** (`insights.js`) находят аномалии и считают цифры: кампании с CPL выше среднего при
   худшей квалификации, обвал конверсии в воронке бота, менеджеров с длинным циклом, отставание от плана,
   лучший канал по ROMI, источники с высокими отказами. Работают всегда — без ключей и без интернета.
2. **Claude API** получает и данные, и найденные правилами аномалии и формулирует выводы для руководителя.
   Модель не придумывает числа: считают правила, модель объясняет и приоритизирует.

Если ключа нет или API недоступен — дашборд остаётся с инсайтами по правилам, это осознанный фолбэк.

## Автообновление и уведомления

- `automation/github-actions.yml` — ежедневная пересборка и коммит свежих данных.
- `automation/cron-worker.md` — тот же пайплайн на cron-триггере Cloudflare Worker.
- Дайджест уходит в Telegram при `--notify`; при `notify.onlyIfCritical: true` — только если есть критичный инсайт,
  чтобы руководителю не приходило «всё хорошо» каждый день.

## Демо-данные

`demo_source.js` — детерминированный генератор: одни и те же цифры при каждом запуске.
В них намеренно зашиты три сюжета, на которых удобно показывать работу инсайтов:
разгон дорогой кампании в РСЯ, поломка шага квиза в боте с 18-го дня и медленный менеджер в отделе продаж.
