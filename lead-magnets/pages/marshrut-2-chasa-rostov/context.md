## Бриф

- **Компания:** МотоКум (motokum.ru) — прокат мотоциклов, Ростов-на-Дону
- **Телефон:** +7 929 590-88-32
- **Тон бренда:** неформальный, дружеский, "свой человек", а не официальный сервис
- **Модели в прокате:**
  - Yamaha MT-07 (нейкед, 689 см³, от 3 500 ₽/сутки)
  - Honda CB500X (турэндуро, 471 см³, от 3 200 ₽/сутки)
  - Kawasaki Z650 (нейкед, 649 см³, от 3 300 ₽/сутки)
  - BMW G310R (для новичков, 313 см³, от 2 800 ₽/сутки)
- **ЦА лид-магнита:** люди с правами категории А, проезжающие/приезжающие в Ростов без своего мотоцикла, хотят покататься по городу
- **Тема:** обзорный маршрут по Ростову на 2 часа — топ-места посмотреть на мотоцикле
- **CTA:** позвонить и забронировать мотоцикл

## Решения, принятые в демо-режиме (без фаз аудита/конкурентов)

- Топ-места маршрута выбраны без клиента, по типовым достопримечательностям: набережная Дона → Соборная площадь → Театральная площадь → Парамоновские склады → Ворошиловский мост
- Телефон для CTA — существующий номер сайта
- Дизайн — стиль "мото-гараж": чёрный/жёлтый, брутально, шрифты Oswald (заголовки) + Rubik (текст)
- Формат — интерактивный лонгрид (не PDF), с квизом, опросом, чек-листом и формой заявки

## Смелые идеи интерактива (на будущее)

1. **Интерактивная карта-таймер** — SVG/canvas карта Ростова с 5 точками; клик по точке показывает фото/факт, сверху тикает таймер "осталось 118 минут"
2. **Слайдер "сколько успеешь за 2 часа"** — перетаскиваешь время (1ч / 2ч / полдня), точки маршрута подсвечиваются/гаснут — подталкивает взять подольше
3. **Калькулятор "сколько будет стоить прокат под твой маршрут"** — выбор модели + часы → цена и кнопка "забронировать это"
4. **"Собери свой маршрут"** — drag&drop/чекбоксы из 8-10 точек, выбираешь любые 5, страница считает время и генерирует "твой маршрут" для отправки в Telegram
5. **Мини-игра на реакцию/баланс** ("жми в момент зелёного") с результатом-подводкой к модели мотоцикла — крючок для шеринга
6. **Живой counter/social proof** — "сегодня по этому маршруту уже проехали N человек"
7. **Аудио-байки на точках маршрута** — 20-секундные голосовые вставки в тоне "своего человека" из МотоКум
8. **Погодный/временной виджет** — "сейчас 18:32, до заката 2ч 40м — успеешь доехать до Ворошиловского моста на закате"

Для демо/воркшопа лучше всего заходят **#1 (карта-таймер)** и **#3 (калькулятор)** — наглядный "вау-эффект", собираются быстро на чистом JS без библиотек.
