## Логика скилла (как на слайде «Логика скилла»)

1. Бриф — продукт, оффер, гео, бюджет, цена заявки; без ответов дальше не идёт.
2. Проверка цели — какая цель Метрики настоящая заявка, сверка с CRM; расходится — просит починить.
3. Подключение — Директ, Метрика, Вордстат, проверочный запрос.
4. Сборка — спрос → группы фраз → тексты под лимиты → баннеры → минус-слова.
5. Показ — всё до загрузки, ждёт «да» или правок.
6. Запуск — только поиск, сети выключены, отправка на модерацию.
7. Автопилот — каждый час расход, каждое утро минус-слова на согласование, раз в неделю отчёт.

Правила: деньги только через «да»; пауза при перерасходе срабатывает сама; стратегию не трогает чаще раза в 1–2 недели.
