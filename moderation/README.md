# Модерация клубных чатов

Новые участники клубных чатов не могут писать, пока не заполнят анкету у бота @cmo_razbory_bot.

## Как работает

1. Человек входит в чат по ссылке-приглашению. Бот помечает его как новичка.
2. Пока анкеты нет, каждое его сообщение сразу удаляется. Напоминание «заполни анкету» с кнопкой бот присылает в личку, его видит только сам человек.
3. Если человек ни разу не запускал бота, Telegram не даёт боту написать первым. Тогда в чате на 15 секунд появляется сообщение с упоминанием и кнопкой «Заполнить анкету», потом бот его удаляет. Не чаще раза в минуту на человека.
4. Анкета идёт в личке, вопрос за вопросом. Необязательные вопросы можно пропустить кнопкой или ответом «-». Контакт в Telegram бот берёт из @username сам.
5. После анкеты визитка публикуется в чат клуба, ответы уходят в Google Таблицу (своя вкладка на клуб), и человек может писать.
6. Для ссылок «по заявке» бот сразу присылает анкету в личку подавшему заявку. Одобряют заявки по-прежнему админы клуба.

Участники, которые были в чате до подключения бота, и админы чата не ограничиваются.

## Подключение

1. В каждом чате сделать @cmo_razbory_bot администратором с правом **«Удаление сообщений»**. Для заявок на вступление — ещё «Добавление участников».
2. Задеплоить воркер: `wrangler deploy`.
3. Открыть `/setup-webhook` на домене воркера: бот начнёт получать входы в чат (`chat_member`) и заявки (`chat_join_request`).
4. Google Таблица: вставить `moderation/apps-script.gs` в Apps Script таблицы, опубликовать как веб-приложение и задать секреты:
   ```
   wrangler secret put MOD_SHEET_WEBHOOK   # URL веб-приложения Apps Script
   wrangler secret put MOD_SHEET_SECRET    # необязательно, то же значение, что SECRET в свойствах скрипта
   ```
   Пока секрет не задан, анкеты хранятся в KV (`mod:anketa:<клуб>:<tgId>`), а админу приходит предупреждение.

## Ключи KV

- `mod:new:<chat>:<user>` — новичок, вошёл после подключения бота
- `mod:ok:<club>:<user>` — анкета заполнена, можно писать
- `mod:anketa:<club>:<user>` — ответы анкеты
- `mod:state:<user>` — анкета в процессе
- `mod:sheetfail:<club>:<user>` — анкета, которая не записалась в таблицу
