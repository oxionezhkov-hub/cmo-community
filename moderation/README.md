# Модерация клубных чатов

Новые участники клубных чатов не могут писать, пока не заполнят анкету у бота @cmo_razbory_bot.

## Как работает

1. Человек входит в чат по ссылке-приглашению. Бот помечает его как новичка и сразу показывает в чате приветствие с кнопкой «Заполнить анкету». Это эфемерное сообщение (Bot API 10.2+): его видит только этот человек.
2. Пока анкеты нет, каждое его сообщение сразу удаляется. В чате появляется эфемерное «Сообщение не отправлено — сначала заполни анкету», видное только ему, не чаще раза в 20 секунд. Если человек запускал бота, копия с кнопкой приходит и в личку.
3. Запасной вариант, если эфемерное сообщение не прошло и в личку написать нельзя: обычная подсказка в чате на 15 секунд, потом бот её удаляет. Не чаще раза в минуту на человека.
4. Анкета идёт в личке, вопрос за вопросом. Необязательные вопросы можно пропустить кнопкой или ответом «-». Контакт в Telegram бот берёт из @username сам.
5. После анкеты ответы уходят в Google Таблицу (своя вкладка на клуб), и человек может писать. Визитка в чат не публикуется.
6. **Заявки принимаются автоматически.** По ссылке «по заявке» человек сразу попадает в чат и может его читать без «подписки»: бот пишет ему в личку «заявка принята, чтобы писать — заполни анкету», принимает заявку и показывает в самом чате приветствие с кнопкой анкеты, которое видит только он. Писать можно после анкеты, до неё сообщения удаляются. Доверенных и уже заполнивших анкету бот просто принимает. Боту нужно право «Добавление участников», иначе админу придёт предупреждение.

Участники, которые были в чате до подключения бота, и админы чата не ограничиваются.

Служебные сообщения «X вступил(а) / покинул(а) группу» бот в клубных чатах сразу удаляет: они засоряли чат и давали уведомления всем участникам. Запасная подсказка в чате (если эфемерное сообщение не прошло) отправляется беззвучно.

Кнопка «Заполнить анкету» везде — ссылка на бота со «Стартом» (`t.me/cmo_razbory_bot?start=mod_<клуб>`). Callback-кнопка не годится: если человек ни разу не запускал бота, после приёма заявки бот уже не может ему написать, и кнопка «молчала». Повторное нажатие не сбрасывает анкету, а возвращает к текущему вопросу.

## Одна анкета на все клубы

Анкета заполняется один раз. Если человек уже заполнил её в одном клубе, в другом клубе (вход, заявка, сообщение, кнопка анкеты) бот переносит те же ответы: доступ открывается сразу, строка появляется во вкладке нового клуба, в журнале — «Заполнил анкету · перенесена из …». Если у клуба есть обязательные вопросы, которых не было в прошлой анкете, бот спрашивает только их. Если человек ждёт анкету сразу в нескольких клубах, одна анкета открывает доступ во все.

## Ссылка на анкету

`https://t.me/cmo_razbory_bot?start=anketa` — одна ссылка для напоминаний в личке. Бот сам откроет анкету того клуба, где человек её ждёт. Если анкета уже есть — скажет, что можно писать. Если бот не знает, о каком клубе речь, — покажет кнопки клубов.

Ссылки на конкретный клуб: `?start=mod_edtech`, `mod_agency`, `mod_sales`, `mod_ai`.

## Журнал модерации

Страница https://cmo-razbory.oxion-ezhkov.workers.dev/moderation, вход по паролю админки. На ней полный журнал по четырём клубным чатам:

- события: вошёл в чат, заявка принята автоматически (или не удалось), сообщение удалено (с текстом), начал анкету, заполнил анкету, добавлен в доверенные или убран, анкета не записалась в таблицу;
- период: 7, 30, 90 дней, год или свои даты;
- фильтры: клуб, событие (выпадающий список или чипы с количеством), поиск по имени, @username или id. Клик по человеку показывает все его события;
- сортировка по клику на заголовок: дата, клуб, человек, событие, детали;
- выгрузка отфильтрованного в CSV.

Журнал хранится в KV по дням (`modlog:day:YYYY-MM-DD`, по Москве, 400 дней). При первом открытии в него дописывается то, что бот уже знал раньше: заполненные анкеты, отметки входа новичков, доверенные.

## Доверенные: писать без анкеты

Олег (`ADMIN_ID`) и Дима (`345618009`) могут дать человеку право писать во всех клубных чатах без анкеты. Для этого боту в личку отправляется одно из:

- `@username` или ссылка `t.me/username`;
- числовой Telegram id;
- пересланное сообщение этого человека (если он не скрыл аккаунт в пересылке).

Бот отвечает «✅ может писать без анкеты» с кнопкой «↩️ Отменить», второй админ получает уведомление. Команды:

- `/trusted` — список доверенных;
- `/untrust @username` (или id) — забрать доступ.

Список админов — `MOD_TRUST_ADMINS` в `moderation/moderation.js`.

## Подключение

1. В каждом чате сделать @cmo_razbory_bot администратором с правом **«Удаление сообщений»**. Для заявок на вступление — ещё «Добавление участников».
2. Задеплоить воркер: `wrangler deploy`.
3. Открыть `/setup-webhook` на домене воркера: бот начнёт получать входы в чат (`chat_member`) и заявки (`chat_join_request`).
4. Google Таблица: вставить `moderation/apps-script.gs` в Apps Script таблицы, опубликовать как веб-приложение и задать секреты:
   ```
   wrangler secret put MOD_SHEET_WEBHOOK   # URL веб-приложения Apps Script
   wrangler secret put MOD_SHEET_SECRET    # необязательно, то же значение, что SECRET в свойствах скрипта
   ```
   Пока секрет не задан, анкеты хранятся в KV (`mod:anketa:<клуб>:<tgId>`), а админу приходит предупреждение.

## Ключи KV

- `mod:new:<chat>:<user>` — новичок, вошёл после подключения бота
- `mod:ok:<club>:<user>` — анкета заполнена, можно писать
- `mod:anketa:<club>:<user>` — ответы анкеты
- `mod:state:<user>` — анкета в процессе
- `mod:sheetfail:<club>:<user>` — анкета, которая не записалась в таблицу
